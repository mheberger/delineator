# Static: Interactive local web app files for the `delineator` Python package

The file `index.html` is for the provided web app demo. If you open this in 
your web browser, it can't do anything. You need to have the backend running.

After installing the delineator package, run the following command in the terminal:

```bash
delineator_serve
```

Open your web browser and visit http://localhost:5000.
